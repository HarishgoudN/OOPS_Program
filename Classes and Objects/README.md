# Classes and Objects

This folder introduces the basic building blocks of Object-Oriented Programming in C++ through classes and objects.

## Topics Covered

* Classes
* Objects
* Data members
* Member functions
* Private and public members
* Object creation
* Encapsulation
* Defining member functions outside a class
* Scope resolution operator `::`

The programs demonstrate how classes can be used to organize data and functions into reusable objects.

# C++ Fundamentals

This folder contains basic C++ programs covering fundamental programming concepts, input and output, data types, strings, functions, and different methods of passing arguments.

## Programs

| **Filename** | **Description** |
| ------------ | --------------- |
| `basic_output.cpp` | Demonstrates basic output using `cout` |
| `input_and_addition.cpp` | Accepts two numbers and displays their sum |
| `variable_data_types.cpp` | Demonstrates variables and fundamental data types |
| `rectangle_area.cpp` | Calculates the area of a rectangle |
| `largest_in_list.cpp` | Finds the largest value in a collection of numbers |
| `string_length.cpp` | Determines the length of C-style and C++-style strings |
| `c_string_palindrome.cpp` | Checks whether a C-style string is a palindrome |
| `cpp_string_palindrome_practice.cpp` | Practice program for palindrome checking using C++ strings |
| `pass_by_value.cpp` | Demonstrates passing arguments by value |
| `pass_by_reference.cpp` | Demonstrates passing arguments by reference |
| `pass_by_pointer.cpp` | Demonstrates passing arguments using pointers |

## Concepts Covered

- Basic C++ syntax
- `cin` and `cout`
- Variables and data types
- Arithmetic operations
- Strings
- C-style strings
- C++ strings
- Palindrome checking
- Functions
- Pass by value
- Pass by reference
- Pass by pointer

# C++ Fundamentals

This folder contains introductory C++ programs that build the foundation for Object-Oriented Programming.

## Topics Covered

* Basic C++ syntax
* Input and output using `cin` and `cout`
* Variables and data types
* Arithmetic operations
* Strings
* C-style and C++-style strings
* Palindrome checking
* Functions
* Pass by value
* Pass by reference
* Pass by pointer

The programs in this folder focus on developing fundamental C++ programming skills required for the concepts covered in the following sections.
